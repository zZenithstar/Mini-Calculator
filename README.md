# Mini-Calculator
A functional mini-calculator written in Python.

Hello everyone! This is a mini-calculator I created—a compact, ideal project that is perfect for beginners.

Features
It performs mathematical operations such as addition, subtraction, multiplication, division, percentage calculations, and exponentiation.
It features both a light theme and a dark theme for night-time use.
It logs every operation in a dedicated section, allowing you to review your history whenever you wish.
It was designed with a futuristic aesthetic.

*Built using Python 3.14.
